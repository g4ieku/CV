# Grzegorz Czekaj – CV website

A one-page CV built with plain HTML and CSS: no build step, no JavaScript.

| File | Purpose |
| --- | --- |
| `index.html` | Page content |
| `style.css` | Layout, colours, light/dark mode, phone layout |
| `photo.jpg` | Profile photo |
| `CV-Grzegorz-Czekaj.pdf` | The PDF CV behind the "Download CV" button |

## Publish on GitHub Pages

1. Put these four files in the root of the `CV` repository (replace the old ones).
2. Commit and push to the default branch.
3. In the repository go to **Settings → Pages**, choose **Deploy from a branch**, select the default branch and the `/ (root)` folder.
4. After a minute the site is live at https://g4ieku.github.io/CV/

## Updating

- Edit the text directly in `index.html`.
- When the PDF CV changes, replace `CV-Grzegorz-Czekaj.pdf` with the new file under the same name.
